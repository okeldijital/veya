# Veya V1 Scope

## Objective

Enable a new user to create and publish a useful, attractive link-in-bio page in under five minutes.

## Core scope

- Account creation and authentication
- Unique username and public profile URL
- Profile photo, display name and bio
- Add, edit, delete, enable/disable and reorder links
- Social links
- Basic themes and appearance controls
- Live mobile/desktop preview
- Publish/unpublish profile
- Basic profile and link analytics
- QR code generation
- Copy/share public profile URL

## Non-goals

- Campaign management
- Multiple public pages
- Email marketing
- CRM/audience management
- Payments, bookings, donations or digital products
- EPK management
- A/B testing
- AI optimisation
- Advanced analytics
- Team collaboration
- Custom domains
- Public API
- Integration marketplace

## UX acceptance criteria

- A first-time user should understand what to do next without documentation.
- Strong defaults should produce a good-looking page with minimal configuration.
- Mobile is the primary public viewing context.
- Advanced concepts should not be exposed during the basic creation flow.
- Public pages should be fast and lightweight.

## Roadmap direction

V1 Core → Presentation → Growth → Audience → Business → Intelligence.
