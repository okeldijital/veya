# Veya V1 Implementation Plan

## Phase 0 — Foundation
- Initialize Next.js App Router application
- Establish TypeScript and linting/formatting standards
- Establish environment configuration
- Establish base UI shell and design tokens
- Establish deployment target on Vercel

## Phase 1 — Identity
- Authentication
- User account
- Profile creation
- Username availability and reservation
- Public profile route

## Phase 2 — Core editor
- Profile editor
- Link CRUD
- Link enable/disable
- Link ordering
- Social links
- Live preview

## Phase 3 — Presentation
- Theme presets
- Appearance controls
- Responsive public profile
- Empty/draft/published states

## Phase 4 — Analytics and sharing
- Profile views
- Link clicks
- Basic dashboard reporting
- QR generation
- Share/copy profile URL

## Phase 5 — Validation
- Functional testing
- Mobile/desktop verification
- Accessibility review
- Performance review
- Production readiness review

## Release gate
V1 is not complete until the complete first-time-user flow works from signup through published public profile and basic analytics.
