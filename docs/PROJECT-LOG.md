# Veya Project Log

## 2026-08-27 — Project initialization

### Decisions
- Working product name: **Veya**.
- V1 is a lightweight link-in-bio MVP.
- Development/staging domain: `linkbio.okeldijital.africa`.
- Dedicated production domain will be selected after validation.
- Lnk.Bio is a functional benchmark for basic expectations, not a feature-by-feature implementation target.
- Simplicity and user-friendliness are primary product constraints.
- Advanced capabilities will be introduced incrementally after the core product is stable and validated.

### V1 scope
Profile, username, links, social links, themes/appearance, live preview, publishing, basic analytics, QR code and sharing.
