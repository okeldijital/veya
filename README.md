# Veya

Veya is a lightweight, user-friendly link-in-bio platform by Okel Dijital.

## V1

The MVP focuses on the core link-in-bio experience:

- Account creation and authentication
- Unique username and public profile URL
- Profile photo, display name and bio
- Add, edit, delete, enable/disable and reorder links
- Social links
- Basic themes and appearance controls
- Live mobile/desktop preview
- Publish/unpublish profile
- Basic profile and link analytics
- QR code generation
- Copy/share public profile URL

## Product principle

**Every feature must make Veya more useful without making Veya harder to use.**

V1 deliberately avoids advanced capabilities such as campaigns, CRM, commerce, bookings, AI optimisation and advanced analytics. These will be introduced incrementally after the core experience is stable and validated.

## Development

Development/staging URL: `https://linkbio.okeldijital.africa`

The development domain is temporary. A dedicated Veya production domain will be selected after validation.
